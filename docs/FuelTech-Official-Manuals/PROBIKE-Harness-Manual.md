## Why it matters to the Turbo V-Rod project

This is FuelTech's motorcycle-specific FT450/FT550 harness reference and is especially useful for validating the electrical architecture around:

- FT550 A/B connector usage
- battery positive and battery negative routing
- separate relay/fuse feeds for ECU electronics, injectors and coils
- sensor 5 V and sensor ground distribution
- CAN A and CAN B
- crank and cam Hall/VR interfaces
- injector and ignition outputs
- pressure, temperature, TPS, speed and gear inputs
- auxiliary inputs and outputs

The PROBIKE harness is not a direct V-Rod harness design. It is a useful FuelTech reference architecture. The Turbo V-Rod implementation should retain the relevant FuelTech requirements while applying the project's EPM/APM/SIM segregation and V-Rod-specific sensors, actuators and turbo hardware.
